# Kotlin Coroutines App

A simple Android application demonstrating the basics of **Kotlin Coroutines** and background thread management.

## Features
- Background file download simulation using `Dispatchers.IO`.
- Thread switching between Main and IO dispatchers using `withContext`.
- Non-blocking execution with `delay()`.

## Getting Started
1. Clone the repository.
2. Open the project in Android Studio.
3. Run the app on an emulator or physical device.
